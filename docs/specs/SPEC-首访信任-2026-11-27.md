### 3.1 裁决 A —— F3 首页降级提示的挂载点：**分类流上方（页面级横幅），不进 Bento 网格**

**结论（已冻结）**：降级条挂在 `navigation-content.tsx` 内容区顶层——`HomeLocalPacksStrip`（`:2084`）之后、`viewMode === 'workbench' ? … : …` 三目（`:2097`）之前，实际渲染在 `:2089-2095`。**不进入 Bento 网格**。

**依据**：
1. **全仓既有用法一致**：实测 `grep -rn "HubDegradedNotice" apps/web-overlay/src` = **42 处命中**，拆解为 **17 个源文件、20 个 JSX 渲染点**（另 1 处定义于 `components/hub-degraded-notice.tsx:14`、4 处注释引用；`apps/web-overlay/test` 另有 11 处断言引用）。**20 个渲染点全部是「内容之上的页级横幅」，无一挂在网格块内**——`apps/web-overlay/src/app/hot/hot-view.tsx:697`（`{notice && <HubDegradedNotice notice={notice} onRetry={reload} />}`，位于筛选栏/榜单之前）、`tag-cloud.tsx:223`、`collection-board.tsx:160`、`plugin-market-board.tsx:854`、`admin/plugins/page.tsx:1072`、`admin/site-reports/page.tsx:145`。首页挂载点选同一相对位置，用户跨页看到的是同一种「顶部黄条」语义。
   > 计数口径说明：同一文件内多个 `<HubDegradedNotice` 各计一点（`site-detail-view.tsx:477/642`、`plugin-detail-view.tsx:418/489`、`author-plugins-view.tsx:217/442` 各 2 点），故 17 文件 ≠ 20 点。
2. **Bento 是用户持久化的布局，不是渲染槽**：网格块来自 `renderBlock` + `availableWorkspaceBlocks`（`navigation-content.tsx:1422`，由 `renderedCategories` `:967` 派生），布局按断点持久化并经 `commitWorkspaceBreakpointLayout`（`:544`、`:2171`）落盘。把运行时状态塞成网格块会：① 降级瞬间 layout 凭空多一项；② 用户在降级态保存布局会把降级提示持久化进 DIY 配置；③ 提示条可被拖走/删掉——安全提示不能是可删除项。
3. **挂载点覆盖两种模式**：在 `:2084` 与 `:2097` 之间，workbench（`:2097-2113`）与常规分类流（`:2114+`，含 Bento 网格 `:2161`/`:2186` 与空态 `:2196-2213`）都能看到，且位于 `DiyGridDragBoundary`（`:2116`）之外。

### 3.2 裁决 B —— `topSearchHotkeyMatches` 是否加 `mode`：**加**，默认参数保持兼容

**结论（已冻结，优先于 PRD §6 第 8 条「不动签名」）**：**加**，并按下述签名冻结。

```ts
// apps/web-overlay/src/lib/user-preferences.ts:217
// 现签名：topSearchHotkeyMatches(event: KeyboardEvent): boolean
// 冻结签名：
export function topSearchHotkeyMatches(
  event: KeyboardEvent,
  mode: SpotlightShortcutMode = 'both',
): boolean
```

**语义（逐条可断言）**：

| mode | mod+K（无 Shift） | mod+Shift+K | / |
|---|---|---|---|
| `'both'`（默认） | 命中顶栏聚焦 | 开弹窗 | 开弹窗 |
| `'mod+k'` | 命中顶栏聚焦 | 开弹窗 | 不响应 |
| `'slash'` | **不命中、不 preventDefault** | 不响应 | 开弹窗 |

即：`mode === 'slash'` 时 `return false`；其余沿用现有实现 `Boolean((event.metaKey || event.ctrlKey) && !event.shiftKey && key.toLowerCase() === 'k')`（`:217-224`）。
