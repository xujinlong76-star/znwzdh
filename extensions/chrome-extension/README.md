# NavHub 智能导航随身助手 (Chrome / Edge 扩展)

NavHub 4.0 官方浏览器随身扩展，将 NavHub 从标签页解放为全场景生产力随身外脑。

## 功能亮点

1. **Omnibox 地址栏极速搜索**：
   - 在 Chrome / Edge 地址栏输入 `nh` 然后按 `Space` 或 `Tab`，即可直接触发 NavHub 离线向量与全文混合检索，实时展示匹配结果并按回车秒级直达。
2. **一键智能网页收录**：
   - 点击浏览器右上角 NavHub 扩展图标，一键将当前打开的页面提交至 NavHub 中枢。
   - 自动触发后端 AI 智能抓取、生成标题、分类归纳与标签富化。
3. **随身搜索面板**：
   - 无论处于何种工作界面，点击扩展面板即可毫秒级查询站库、探索平替与直达微动作。

## 安装指南（开发者模式）

1. 打开浏览器扩展管理页面：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
2. 开启右上角的 **「开发者模式」** 开关。
3. 点击 **「加载已解压的扩展程序」** (Load unpacked)。
4. 选择当前项目的 `extensions/chrome-extension` 目录即可！
5. 在地址栏输入 `nh` 并按空格，立即体验极速导航搜索。
