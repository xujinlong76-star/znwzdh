## API Token 凭据治理（第二轮）

### 定位到的问题
1. **鉴权失败完全不落审计**（最严重）：401/403 只回错误体，审计日志一片空白 → 凭据被滥用/被枚举时运维完全看不见
2. **`rotateApiToken` 把 `created_at` 重置为 now**（真 bug）：轮换后"创建于"跳变，丢失凭据真实服役起点
3. **只有硬删除没有吊销**：删除后 `audit_logs.target` 变悬空 id，无法追溯"哪条凭据做过什么"
4. **`touchApiToken` 每请求一次写库**：在鉴权钩子里无条件执行，MCP Agent 一轮会话上百次请求 = 上百次 UPDATE，SQLite 单写者模型下纯属锁竞争
5. **`expiresAt` 无上限、凭据无数量上限**：可签发永久凭据，可无限签发
6. **前端接不到后端已有能力**：rotate / patch / revoke 三个接口 UI 全都没有入口
7. scopes 用多选 checkbox，但 read/write/admin 是层级关系（admin ⊇ write ⊇ read），语义混乱
8. 复制明文用 `navigator.clipboard` 无降级，非安全上下文会静默失败 → 用户以为复制了其实没有，明文永久丢失

- git push 报 `CRYPT_E_REVOCATION_OFFLINE`（schannel 吊销检查）→ 仓库级 `git config http.sslBackend openssl` 解决（不要动全局 config；`http.schannelCheckRevoke false` 不够，握手仍失败）
- MSYS 会把 `origin/main:path` 参数当路径转换（`:` → `;`）→ 前置 `MSYS2_ARG_CONV_EXCL='*'`
- `js-yaml` 在 .pnpm store 未提升 → `require('./node_modules/.pnpm/js-yaml@4.3.2/node_modules/js-yaml')`

**冲突解决（6 文件，策略=各取更强方 + 移植对方独有）**：
- **ci.yml**：远端四作业为基底（vendor 重建 apps/web 解决全新检出红灯、正确的 NAVHUB_TEST_DATABASE_URL、最小权限），补回远端丢的两个闸门（test-sqlite 加 `pnpm build`、test-postgres 加 `pnpm test:pg`）+ ci-passed 聚合门
- **mcp/http-server.ts + http.ts**：远端把 MCP HTTP 重写成标准 Streamable HTTP，但**丢掉了 api_tokens 表内 token 鉴权**（管理页签发的 token 不能再用于 MCP——正是凭据治理修掉的脱节）。把表内鉴权移植进远端版 auth()：静态 token 优先 → sha256 查表（findApiTokenByHash 已过滤吊销/过期）→ actor 用 `mcp:<token名>`；http.ts 保留表内感知的启动拒绝
- **embedding.ts**：保留 normalize+singleflight 委托，把远端版的输入截断 2000/空值防护/30s 超时/维度校验收进 compute 回调（远端版还带一个 `return vec; return vec;` 重复行 bug，丢弃）
- migrate.ts / repository.ts / store.test.ts：双方新增取并集

**apps/web 工作副本重建**：远端合并更新了 overlay，但 gitignore 的 apps/web 副本不同步（navigation-content.tsx 引用新函数而 diy-presets.ts 是旧版 → tsc 炸）。`vendor-web.mjs` 本机跑不了（Windows tar 被 MSYS 路径转换搞坏：`tar: Cannot connect to c:`），手动接力：bash tar 相对路径解包 + Node 复刻 overlay 覆写。另 15 个 src 文件 + public/sw.js 逐个 cp 同步后 overlay 校验 180 文件一致
- 注意：Node `cpSync(上游, apps/web)` 被 WorkBuddy fs shim 拦（EIO）→ 用 bash cp 代替

**教训**：
- http-server.ts 不在冲突列表（自动合并），编辑后忘记 `git add`，合并提交差点吞掉表内鉴权——**自动合并的文件改了也要 add**，提交前 `git show HEAD:<file> | grep <特征>` 复核
- `pnpm -r exec tsc` 的输出混入 tsc 帮助文本时，逐包 `npx tsc --noEmit` 定位；沙箱会拦 wmic.exe（某原生模块探测触发），按提示不重试即可
- apps/web（navsphere）与 web-overlay 都不在 CI typecheck 的 `@navhub/*` 过滤内——overlay 类型错误只在 Docker build 暴露
