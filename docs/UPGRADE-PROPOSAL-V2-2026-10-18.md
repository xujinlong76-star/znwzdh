## 一、执行摘要（四个判断）

1. **「重」已解大半，下一步在「拆」。** 首屏路由 JS 685 → **637 KB**（-7%），逐路由预算门禁（首页 669 KB）已进 `verify`；剩余可测空间集中在两处：搜索面板的 **cmdk（56 KB）** 与四个千行级组件的内联逻辑（合计约 **6,800 行**）。
2. **「第一次打开」的体验已补齐，接下来一致性 ＞ 新花样。** 首访引导、13 个路由骨架、7 个错误边界、空态样板、动效 token 都已落地；缺口在**逐页迁移**（空态 / 色值 / 动效）与**分享传播**（DIY 分享仍是 `#diy=base64` 长链）。
3. **安全从「缺失」变成「未收口」。** CSP report-only 档、客户端错误上报闭环、COOP/CORP 响应头都已备好，但**都默认关**；enforce、next-auth `5.0.0-beta.32` 处置、管理端 2FA 三件事还没做。
4. **此刻最优先的不是新功能，而是「落盘」。** 80+ 项升级成果停在工作树；CI 的 8 个作业（含 **PostgreSQL / Docker 冒烟 / E2E / audit**）**从未跑过这批代码**——「本机绿」尚未变成「可复现绿」。

## 四、P0 —— 本周（低风险、纯增量）

### P0-0 落盘与 CI 首航（工程/风险）

- **现状**：全部升级成果（P0 全部、P1 主体、P2 三批）停在工作树，未提交；CI 8 个作业从未跑过这批代码；本地因无 Docker 常态化跳过 15 例 PG 测试。
- **动作**：① 在途改动收尾后按主题做 6–8 个原子提交（或单合并提交）；② push 后盯 CI 首航，重点排查 PG 方言下的 `storage`/`health` 改动、`docker-smoke`、CI 端 E2E；③ 把 `check:bundle` 与 `check:overlay` 的 CI 覆盖补齐（如尚未覆盖）。
- **预期收益**：把「本机绿」变成「可复现绿」；当前工作成果只存在于工作树，任何磁盘事故即全部丢失。
- **实施考量**：预留 0.5–1 人日修 CI-only 问题；提交前确认无并发写入（本机代理配置见环境备忘）。
- **验收**：`ci-passed` 绿；E2E 首次全量通过留档。

### P0-1 CSP report-only 生产上线（安全）

- **现状**：`NAVHUB_CSP_REPORT_ONLY=1` 档已实现且有 7 例契约测试，但生产默认关；无违规采集端点。
- **动作**：生产开启 RO 档 + `NAVHUB_CSP_REPORT_URI` 指向新增 `POST /api/csp-report`（限速 + 只存摘要，与 `client-errors` 同构，复用 events 表与后台卡片）。
- **预期收益**：为一周后的 enforce 提供真实违规清单；RO 不阻断任何请求，风险≈0。
- **实施考量**：只收集不阻断；注意报告风暴限速；违规涉及第三方域（图片/埋点）时先修清单再切 enforce。
- **验收**：违规 <5 条/天且全部可解释 → 进入 P1-3。

### P0-2 设计系统迁移推进（界面）

- **现状**：样板三件套 + `/favorites` 已迁移；`admin/*` 列表页空态迁移**已在途**（工作树刚开工）；动效 token 仅有定义、尚无页面采纳。
- **动作**：① 完成 admin 列表页 → `<EmptyState>` 迁移与镜像；② 挑 3–5 个高频交互（卡片 hover、dock 出入场、搜索结果浮现）切到 `--duration/--ease` token；③ 把「迁一个勾一个」写回 `docs/DESIGN-SYSTEM.md` 迁移清单。
- **预期收益**：观感一致性从「有样板」走到「有页面」；动效可控（reduced-motion 已全覆盖）。
- **实施考量**：严守契约边界——「就地替换样板，不许顺手重排」；守卫测试已就位。
- **验收**：`design-system.test.ts` 扩展用例绿；admin 空态截图三张；token 采纳清单勾完。

### P0-3 图片管线收尾（性能）

- **现状**：全站裸 `<img>` 仅剩 6 处；`next/image` 未使用（图片量小，引入优化服务收益不成比例）。
- **动作**：6 处逐一补 `width/height`（防 CLS）+ `loading="lazy"` / `decoding="async"`；首屏关键图给 `fetchpriority="high"`。
- **预期收益**：CLS/LCP 边际改善；成本 <0.5 人日。
- **实施考量**：勿为「统一」而引入 `next/image`；纯属性级改动，可随其它改动顺带提交。
- **验收**：扫描归零；Lighthouse CLS 不劣化。

### P0-4 E2E 补三条新交互（体验/质量）

- **现状**：9 个 spec 覆盖老功能；本轮新增的引导、错误边界、批量操作、错误上报均为单测覆盖，无浏览器级验证。
- **动作**：补 ① onboarding 三步可点；② 人为抛错 → 路由错误文案出现；③ 多选 → 批量操作坞；把 `pnpm test:e2e` 纳入提交前建议动作。
- **预期收益**：P1-1 拆分的回归安全网；CI `test-e2e` 不再只验老功能。
- **实施考量**：本地系统 Chrome 直接可跑，无需下载浏览器；尽量避免动画导致的不稳定（已有 etag/可见性断言模式可复用）。
- **验收**：12 个 spec 全绿（本地 + CI）。

### P0-5 覆盖层免联网镜像修复命令（工程护栏）

- **现状**：正向漂移是硬门禁（本次夜间的在途改动就被正确标红），但失败提示指向的 `sync-web-overlay.mjs` 需要联网拉上游 tarball——「改一半、没镜像」的临时红没有低摩擦的恢复路径。
- **动作**：新增 `pnpm mirror:overlay`（零网络）：读取 `check-web-overlay` 的漂移清单，逐对把 overlay 内容复制回 `apps/web`（overlay 为部署源）；提交前可选跑一次快速校验。
- **预期收益**：消灭「半同步」事故的操作层；新人第一次改文件就能走到正确路径。
- **实施考量**：与现有 check 脚本共用 `scripts/lib/overlay-drift.mjs` 纯函数（已有单测）；只处理正向漂移，不动反向候选。
- **验收**：人为制造漂移 → 一条命令回到绿。

## 五、P1 —— 2–4 周（中风险，需排期）

### P1-1 巨型组件拆分收尾（性能/结构）

- **现状**：`navigation-content` 首段已拆（1092 行）；待拆 4 个文件合计 **6,792 行**。
- **动作**：按既定节奏「纯函数先抽测试再搬」——`home-diy-toolbar`（浮动工具栏 / 批量面板 / 设置抽屉）→ `use-home-diy`（持久化 / 预设 / 导入导出）→ `admin/sitelist`（筛选 / 批量编辑 / 表格列）；`algorithm-lab` 最后（独立低频页）。
- **预期收益**：首页可测空间再降（配合 P1-2 冲 ≤600 KB）；测试累计 +30 例。
- **实施考量**：多日重构、单文件隔离提交、每步 verify；行为不变性是底线；与在途的 admin 空态迁移串行。
- **验收**：4 个文件各 ≤800 行；相关测试 +30 例；bundle 目标达成后同步下调预算。

### P1-2 搜索面板瘦身（性能）

- **现状**：cmdk 约 56 KB，承载面板方向键导航；替换需重写键盘模型（exec 报告已点名为主要剩余空间）。
- **动作**：自研轻量列表（虚拟滚动）+ 维持现有后端检索不动；键盘模型（↑↓/Enter/Esc/焦点返回）先在 P0-4 的 e2e 里固化。
- **预期收益**：首页 -40~56 KB；面板打开更快。
- **实施考量**：**不引入新依赖**；键盘可达性是最大回归风险，必须与 e2e 同步上。
- **验收**：预算复评达标（≤600 KB 目标）；键盘用例全绿。

### P1-3 CSP enforce 化（安全）

- **现状**：enforce 档含 `unsafe-inline/unsafe-eval`，默认关；RO 档可在 P0-1 后提供数据。
- **动作**：基于 RO 数据修清单 → Next `headers()` 注入 nonce + `strict-dynamic` → 移除生产 `unsafe-eval`（dev 放宽）→ 灰度一台/一域 → 默认 enforce。
- **预期收益**：XSS 攻击面显著收窄；满足企业采购安全问卷。
- **实施考量**：保留三档开关（关 / RO / enforce）随时回滚；内联样式与埋点脚本是第一批要修的违规源。
- **验收**：enforce 档下全量 e2e 绿；违规 <5 条/天。

### P1-4 身份与权限加固（安全）

- **现状**：`next-auth@5.0.0-beta.32`（beta 线上跑）；管理端仅密码/Token。
- **动作**：① auth 路线决策（升 5.x stable，或锁版本 + 明确迁移窗口，登录全链路回归前置）；② 管理端 TOTP + 恢复码；③ 登录失败锁定（5 次/15 分钟）。
- **预期收益**：账号接管风险下降；企业化前置。
- **实施考量**：登录链路 E2E 全绿才放行；2FA 含恢复码约 5 人日。
- **验收**：登录 e2e 全绿；2FA 开关可统计。

### P1-5 分享体系：短链 + 落地页 + OG（功能）

- **现状**：DIY 分享是 `#diy=<base64>` 长链（`lib/diy-share-link.ts`），无服务端存储、无预览；是「V1 里对用户最可见」的一项。
- **动作**：`POST /api/share` 生成短码（布局 JSON + 过期时间）→ `GET /s/[code]` 预览 + 一键应用 → OG 图（标题 + 分类数 + 强调色）→ 收藏夹公开只读分享。
- **预期收益**：分享从「复制一坨 base64」变成可传播短链；自然流量与回访。
- **实施考量**：5–8 人日；内容安全（审核 / 举报 / 过期清理复用 retention）；隐私默认私有；与 P3-3 主题市场共用底座。
- **验收**：创建 → 打开 → 应用 <3 步；OG 正确渲染。

### P1-6 PWA 与离线深化（体验）

- **现状**：离线第一块（最近访问快照）已落地；安装引导、首页卡片离线记录、离线搜索未做。
- **动作**：① 安装引导（访问 3 次后提示）；② 首页卡片点击的离线记录（卡片是 `<Link>`，先收口统一记录入口）；③ 离线搜索走本地索引（`client-vector-search` 已存在）；④ sw 更新策略复核。
- **预期收益**：地铁/弱网可用；桌面安装率提升。
- **实施考量**：缓存版本与 sw 更新谨慎（避免用户卡旧版）；离线数据只读边界明确。
- **验收**：断网可开首页 + 最近站点；离线搜索命中。

### P1-7 设计系统 v2：四态矩阵 + 暗色审计 + 裸色值清零（界面）

- **实施考量**：3–5 人日（分页推进）；勿一次性全家桶替换，守住「守卫测试 + 逐页」节奏。

## 九、反目标（明确不做）

1. **不重写上游 vendored 代码**——继续用 overlay 覆盖层机制，保持「上游可升级」生命线（沿用 V1）。
2. **不为拆分而拆分**——行为不变；纯函数先测试后搬（沿用 V1）。
3. **不引入 `next/image` 优化服务依赖**（图片量小，收益不成比例）；**不为 cmdk 引入新库**（自研轻量）。
4. **不在无 report-only 数据前 enforce CSP**（沿用 V1）。
5. **不同时开多租户与分享两条大改**（沿用 V1）；**不在 CI 首航前叠加新的大重构**。
6. **不做强制遮罩引导**（沿用 V1）；**不做「全家桶式」设计系统替换**（守卫 + 逐页）。
7. **不用「加工具链」解决组织问题**——镜像同步用现有脚本 + 门禁收口（P0-5），不引入新机制。

## 十、风险与回滚

| 风险 | 触发场景 | 预案 |
| :--- | :--- | :--- |
| CI 首航爆环境差异 | PG 方言 / docker-smoke / CI E2E | 预留 0.5–1 人日；单点修复、不夹带新改动 |
| CSP enforce 打挂页面 | 三方脚本 / 内联样式 | 三档开关（关/RO/enforce）一键回退；先灰度 |
| cmdk 替换键盘回归 | 方向键 / 焦点返回失效 | 先在 E2E 固化键盘行为；旧面板保留一版可切回 |
| 组件拆分引入回归 | 状态提升 / 闭包依赖 | 单文件隔离提交；每步 verify；纯函数测试先行 |
| 镜像半同步（本次已发生） | 改到一半的临时漂移 | check 门禁已能标红；P0-5 免联网一键修复 |
| 共享内容风险 | 短链分享违规内容 | 审核 / 举报 / 过期清理；隐私默认私有 |

## 十一、一页结论

- **先做 5 件小事（一周）**：落盘与 CI 首航、CSP report-only、设计系统迁移推进、图片收尾、E2E 补三条——全部低风险，且为后续提供可复现性。
- **再做 7 件中事（一学期四周）**：拆分收尾、cmdk 瘦身、CSP enforce、身份加固、分享短链、PWA 深化、设计系统 v2——直接决定「每次打开」的质量与传播能力。
- **然后 5+4 件大事（两月到一季）**：PG 一等公民、多租户、搜索 2.0、滥用防护、扩展生态；单源化、国际化、市场、实验框架立项。
- **判断标准只有一个**：新用户是否在 30 秒内完成「找到 → 收藏 → 下次还来」——V1 立的标准，V2 继续用它裁判一切优先级。
