## API Token 凭据治理（第二轮）

### 定位到的问题
1. **鉴权失败完全不落审计**（最严重）：401/403 只回错误体，审计日志一片空白 → 凭据被滥用/被枚举时运维完全看不见
2. **`rotateApiToken` 把 `created_at` 重置为 now**（真 bug）：轮换后"创建于"跳变，丢失凭据真实服役起点
3. **只有硬删除没有吊销**：删除后 `audit_logs.target` 变悬空 id，无法追溯"哪条凭据做过什么"
4. **`touchApiToken` 每请求一次写库**：在鉴权钩子里无条件执行，MCP Agent 一轮会话上百次请求 = 上百次 UPDATE，SQLite 单写者模型下纯属锁竞争
5. **`expiresAt` 无上限、凭据无数量上限**：可签发永久凭据，可无限签发
6. **前端接不到后端已有能力**：rotate / patch / revoke 三个接口 UI 全都没有入口
7. scopes 用多选 checkbox，但 read/write/admin 是层级关系（admin ⊇ write ⊇ read），语义混乱
8. 复制明文用 `navigator.clipboard` 无降级，非安全上下文会静默失败 → 用户以为复制了其实没有，明文永久丢失

### 落地
- store：新增 `revoked_at` / `rotated_at` / `token_prefix` 三列（driver.ts 双方言 DDL + migrate.ts COLUMN_ALTERS + schema.ts drizzle 同步）
- repository：rotate 不再重写 created_at（改记 rotated_at）；新增 `revokeApiToken` 软吊销；`findApiTokenByHash` 排除已吊销；`touchApiToken` 60s 进程内节流（常量 `TOKEN_TOUCH_THROTTLE_MS`）
- api/auth.ts：`tokenPrefixOf(raw)` 取前 12 字符（≈54 位，相对 192 位总熵无枚举价值）
- api/config.ts：新增 `tokenPolicy.maxLifetimeDays`（默认 365）/ `maxActiveTokens`（默认 50）
- api/server.ts：401/403 落审计（**绝不记录凭据本身**，按 IP+动作 10s 节流防撑爆 audit_logs）；创建时校验有效期上限与并存数量上限；新增 `POST /api/tokens/:id/revoke`
- web/tokens/page.tsx 重写：轮换 / 编辑 / 软吊销 / 彻底删除（需输入名称确认）/ 四格统计 / 状态徽章（正常·即将过期·已过期·长期有效·已吊销）/ scopes 改单选"最大权限" / 复制带 execCommand 降级且失败要明确提示 / 显示 token 前缀与"已轮换"
