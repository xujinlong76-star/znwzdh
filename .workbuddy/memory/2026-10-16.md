## API Token 凭据治理（第二轮）

### 定位到的问题
1. **鉴权失败完全不落审计**（最严重）：401/403 只回错误体，审计日志一片空白 → 凭据被滥用/被枚举时运维完全看不见
2. **`rotateApiToken` 把 `created_at` 重置为 now**（真 bug）：轮换后"创建于"跳变，丢失凭据真实服役起点
3. **只有硬删除没有吊销**：删除后 `audit_logs.target` 变悬空 id，无法追溯"哪条凭据做过什么"
4. **`touchApiToken` 每请求一次写库**：在鉴权钩子里无条件执行，MCP Agent 一轮会话上百次请求 = 上百次 UPDATE，SQLite 单写者模型下纯属锁竞争
5. **`expiresAt` 无上限、凭据无数量上限**：可签发永久凭据，可无限签发
6. **前端接不到后端已有能力**：rotate / patch / revoke 三个接口 UI 全都没有入口
7. scopes 用多选 checkbox，但 read/write/admin 是层级关系（admin ⊇ write ⊇ read），语义混乱
8. 复制明文用 `navigator.clipboard` 无降级，非安全上下文会静默失败 → 用户以为复制了其实没有，明文永久丢失
