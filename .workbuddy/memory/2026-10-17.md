## 环境坑（重要）

1. **pnpm 11 链接层会静默断裂**：`pnpm install` 报 "Already up to date" 但 importer 只剩 8 个链接；删 `node_modules/.pnpm-workspace-state-v1.json`、删根目录 `node_modules/.modules.yaml`、删 `apps/web/node_modules`、`--force` 均无法让它重链。可行修复是脚本重建 junction（用 `New-Item -ItemType Junction`，PowerShell 能处理中文路径；`cmd mklink` 传中文路径会失败）。
2. **Docker 构建 web 镜像此前从未被验证**（CI 无 docker job），实际是坏的：
   - overlay 纳入 package.json（React 19）后与上游 lockfile 的 overrides 不匹配 → `ERR_PNPM_LOCKFILE_CONFIG_MISMATCH`；解决：为 `apps/web` 生成**独立** lockfile（`pnpm install --lockfile-only`）并纳入 overlay。
   - pnpm 11 默认忽略安装脚本并报错 `ERR_PNPM_IGNORED_BUILDS`；解决：`apps/web/pnpm-workspace.yaml`（`packages: ['.']` + `allowBuilds`）。注意 **pnpm 11 不再读 package.json 的 `pnpm` 字段**（overrides/allowBuilds 均已迁移）。
3. 并行会话活跃：git HEAD 会被 rebase/push 改写，提交可能报 `cannot lock ref`；重试即可。改动也可能被并行会话一起提交。
