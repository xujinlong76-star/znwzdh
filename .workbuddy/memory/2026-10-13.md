## 全面排错（浏览器实测驱动）

用 agent-browser（真实 Chromium）逐页采集 console/errors + performance entries 排查，发现并修复：

1. **【P0】navhub-api 双重前缀**：`getJson` 拼 BASE='/api/hub' 后调用方又传 '/api/...'，
   实际请求 `/api/hub/api/search` 等全部 404 且被 catch 吞掉 → 搜索结果/标签/榜单/
   收藏云同步/站点详情/管理面板数据全部静默为空。浏览器 performance entries 实锤。
   修复：`hubUrl()` 归一化（兼容 '/api/search'、'/search'、'/api/hub/search' 三种写法），
   回归测试 `apps/web/scripts/navhub-api.test.ts`（tsx 运行）。
2. **Container 不支持 className**：custom/page.tsx 传 className 被静默丢弃 + tsc 报错。
   修复：container.tsx 加 className 合并（cn）。
3. **水合不匹配**：quick-tools-widget / quick-tools-drawer 用 `useState(() => Date.now()/randomUUID())`
   做初始值并直接渲染 → SSR 与客户端文本必不同。修复：初始 0/'' + useEffect 挂载后赋值。
4. **apple-touch-icon 缺失**：Next 15.5 的 metadata.icons.apple 只渲染 meta 不渲染 link，
   改 head 显式 `<link>`。
5. **overlay 漂移**：并行会话直接改 apps/web，手工同步必漏。新建
   `scripts/sync-web-overlay.mjs`（下载上游 tarball 精确 diff：与上游不同/上游没有 → 进 overlay；
   一致 → 移出）。踩坑：Windows 系统 tar 对反斜杠绝对路径 status 2（用相对路径 + cwd）；
   cpSync 个别文件 EPERM 怪错（改 writeFileSync）；排除规则必须覆盖 `.next*` 前缀系列。

环境经验：agent-browser 的持久 daemon 会被沙箱在调用间回收 → 必须**单次调用内**完成
open→采集→close；refs 不跨调用；`wait --load networkidle` 会挂（用 load 或跳过）。
a11y snapshot 的文本拼接（如 "2026NavHub"）是快照工具假象，核实要以原始 HTML 为准。

### 第五轮补测：BUG-8 PWA 从未注册

- 根因：pwa-register.tsx 把 register 挂在 window 'load' 事件，React 水合在 load 之后
  → 回调永不触发。证据：getRegistrations()=0、/sw.js 零请求、离线 ERR_INTERNET_DISCONNECTED
- 修复：effect 内直接 register；失败改 console.warn（不再静默）；sw.js 预缓存失败同样告警
- 复验：注册 1 个/activated、二次访问 controller=true、离线首页 52 卡片
- 教训（复用）：**验收要验行为不是验存在**——我此前只查了"SW 代码在 chunk 里"就判通过，
  实际一次都没注册过。PWA/离线类能力必须查 getRegistrations() 与离线实测
- overlay 同步脚本写入偶发失败 → 加重试后 4/4 通过

### 第六轮：边界探测 + BUG-9 限流分桶

- BUG-9：前端代理不转发客户端 IP + 中枢 trustProxy=false → req.ip 恒为前端进程地址，
  按 IP 限流退化成整站一桶（投稿 5/h：第 6 位访客 429）。
  修复：代理透传 x-forwarded-for + 中枢 Fastify trustProxy（NAVHUB_TRUST_PROXY=0 可关）。
  端到端复验：不同 XFF 独立桶（201/201），同 XFF 第 5/6 次仍 429。
- 排查过确认无问题（勿重复）：limit 越界（zod 1..100）、hit.site 空值守卫、
  收藏 JSON 导入 try/catch、搜索 abort 竞态、JobRunner 锁、代理 502 降级。
- **证伪并回滚的假设**：曾判定 `/api/sites/:id` 不支持 URL 形态而加 by-url 路由——
  实测编码后（%3A%2F%2F）能匹配并返回 200，之前 404 只是 URL 不在库里。
  已回滚，改以测试锁定真实契约。教训：**404 ≠ 路由不匹配，先确认数据存在性**。
