## 三、本次实测到的环境事实

1. **高负载下 git 会 `malloc failed`**（`packfile cannot be mapped`），等几十秒恢复；
   `safe-commit` 的 OOM 会把索引留在旧态，事后 `git reset -- <paths>` 同步。
2. **HTTP 头值必须是 ByteString（ASCII）**：上游 Content-Type 带中文时 undici 直接抛
   `TypeError: character at index 1 has a value of 32570`（已修：剥成 ASCII 再回显）。
3. **块注释里不能写裸露的 `*/` 组合**（如 `**/test/**`）——会提前闭合块注释，
   报 `Unexpected identifier`，指向的是注释里的词，看起来莫名其妙。今天踩了两次。
4. **`replace(cwd + "/")` 在 Windows 上剥不掉前缀**（cwd 用反斜杠），
   绝对路径会被判成「域外文件」。归一到正斜杠再剥。
